About Me

I am a second-year undergraduate student pursuing a degree in Computer and Communication Engineering (CCE).

My engineering education bridges hardware communication channels and software computing systems. I am passionate about exploring how network protocols transmit data, how microcontrollers collect and stream environmental sensor telemetry, and how modern web applications can be engineered to be inclusive, responsive, and universally accessible.

My hands-on academic work focuses on practical problem solving—demonstrated by building an IoT-Based Weather Monitoring System for real-time telemetry acquisition and developing DHARM AI Decision to deliver a structured, accessible web-based decision interface.

Academic Background & Coursework

Computer & Communication Engineering (CCE)

Undergraduate Engineering Program • Currently in Second Year

My coursework balances mathematical rigor, electronic communication systems, and foundational computer science principles:

  • Computer Networks & Data Communication: OSI & TCP/IP protocol models, packet switching, transmission media, and routing fundamentals
  • Data Structures & Algorithms in C/C++: Linear and non-linear structures (arrays, linked lists, stacks, queues, trees), search and sort algorithms, and computational complexity
  • Digital Electronics & Logic Design: Boolean algebra, combinational logic circuits, sequential flip-flops, registers, and timing analysis
  • Signals and Systems: Continuous and discrete-time signal representations, Fourier analysis, sampling theorem, and filtering concepts
  • Microcontrollers & IoT Fundamentals: Embedded C programming, GPIO configuration, ADC conversion, sensor bus interfaces, and IoT hardware prototyping
  • Web Development Fundamentals: HTML5 semantic markup standards, CSS3 layout engines (Flexbox & Grid), responsive web design, and digital accessibility (WCAG 2.1 AA)

Technical Proficiencies

Core proficiencies developed through lab coursework, personal experimentation, and active engineering projects:

IoT & Embedded Systems

Applied in building the IoT-Based Weather Monitoring System:

  • Sensors & Telemetry: Interfacing ambient temperature, relative humidity, and barometric pressure sensor modules
  • Microcontroller Programming: GPIO control, analog-to-digital conversion (ADC), sensor bus communication (I2C/SPI), and serial debugging
  • IoT Connectivity: Data packet streaming over Wi-Fi, environmental telemetry logging, and local status indication

Web Development

Applied in building the DHARM AI Decision web interface:

  • Semantic HTML5: Structured content using native landmarks (<header>, <nav>, <main>, <section>, <article>, <aside>, <footer>)
  • Web Accessibility (a11y): Adherence to WCAG 2.1 AA guidelines, ARIA landmark roles, and complete keyboard navigation support
  • Responsive CSS3: Mobile-first layouts, CSS custom properties (variables), Flexbox, and CSS Grid systems
  • Accessible Forms: Explicit label association (for / id), fieldset grouping with legends, and live-region status feedback

Core Engineering

Fundamental engineering and computational competencies:

  • Network Principles: Layered network architecture, packet flow analysis, IP addressing, subnetting, and client-server communication
  • Programming: C and C++ for algorithmic problem solving and systems programming; Python for scripting and automation
  • Developer Tools: Git & GitHub for version control, VS Code development environment, and browser developer tools for debugging

Academic & Learning Objectives

As I progress through my second year of Computer & Communication Engineering, my active goals are:

  1. Deepen proficiency in IoT hardware-to-cloud communication architectures and real-time telemetry processing pipelines.
  2. Continue building standards-compliant, WCAG-accessible web interfaces using clean semantic HTML5 and responsive CSS.
  3. Advance knowledge of networking protocols, embedded microcontroller design, and reliable software-hardware integration.
